01 / 题目、约束与示例

题意与关键约束 · 学习版

反转单链表，返回新的头节点。

阅读官方完整原题 ↗
输入：[1, 2, 3] 期望结果：[3, 2, 1]

02 / 先把题目读明白

返回新头节点；反转的是节点连接，不是只把值倒着输出。

先确认：什么输入是合法的、最后返回或修改什么。暂时不需要猜算法名称。

03 / 最直接的做法

先把节点放进数组，再按倒序连接，需要O(n)空间。实际上每次只要保存一个后继，就能把节点逐个搬到反向链前面。

04 / 从直接做法推导改进

把已处理区看成一条反向链 prev，cur 指向未处理部分。改 cur.next 之前必须保存原来的后继，否则剩余链会丢失。每次只搬一个节点到反向链头。

prev指向已反转部分，cur指向未处理部分，nxt暂存原后继；先保存nxt再改cur.next。

from typing import List, Optional
from collections import deque, Counter, defaultdict
import heapq
import math

class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev, cur = None, head
        while cur:
            nxt = cur.next  # 先保住未处理部分
            cur.next = prev  # 当前节点接到反向链前面
            prev, cur = cur, nxt
        return prev

# 以下是本地构造与验证；提交力扣时只保留题目要求的类。
def linked(items):
    dummy = tail = ListNode()
    for value in items:
        tail.next = ListNode(value)
        tail = tail.next
    return dummy.next

def values(head):
    result = []
    while head:
        result.append(head.val)
        head = head.next
    return result

if __name__ == "__main__":
    assert values(Solution().reverseList(linked([1,2,3])))==[3,2,1]
    assert Solution().reverseList(None) is None
    print("自测通过")

    def __init__(self, val=0, next=None):

class Solution:
    def mergeTwoLists(self, list1, list2):
        dummy = tail = ListNode()
        while list1 and list2:
            if list1.val <= list2.val:
                tail.next, list1 = list1, list1.next
            else:
