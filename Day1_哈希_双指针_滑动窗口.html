02 / 先把题目读明白

返回两个不同位置的下标，不是两个数值；相同数值可以来自不同下标。

03 / 最直接的做法

先枚举第一个下标，再枚举后面的第二个下标检查和，时间O(n²)。重复工作在于：每选一个数，都重新扫描另一个数。

04 / 从直接做法推导改进

暴力固定一个下标 i，再扫描其他位置寻找配对，重复的是“查找”。把 nums[i]+nums[j]=target 改写成 nums[j]=target-nums[i]，当前元素一旦确定，就只剩一次查找。因为返回下标，哈希表必须存值对应的下标，不能只用集合。

05 / 定义状态与更新规则

seen[value]保存已处理元素的下标；need是当前数缺少的另一半。先查need，再登记当前数，才能排除同一位置配对。

处理 i 之前，seen 只保存下标小于 i 的元素。这句话同时解释了正确性和为什么必须先查再存。哈希查找通常是平均 O(1)，不是任何情况下都恒定。

from typing import List


class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # value -> index：只记录“当前要找的另一半”是否出现过
        seen = {}

        for i, x in enumerate(nums):
            # 固定 x 后，问题从“找两个数”变成“找 target-x 是否出现过”
            need = target - x

            # 先查，再存自己，避免同一个位置被用两次
            if need in seen:
                return [seen[need], i]

            seen[x] = i

        return []

from typing import List
from collections import defaultdict


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # 归一化 key -> 原始单词列表
        groups = defaultdict(list)

        for s in strs:
            # 异位词排序后相同；这个 key 就是它们的“身份证”
            key = "".join(sorted(s))
            groups[key].append(s)

        return list(groups.values())

02 / 先把题目读明白

连续指数字值相邻，不要求在原数组中相邻；重复值不增加长度。

先确认：什么输入是合法的、最后返回或修改什么。暂时不需要猜算法名称。

03 / 最直接的做法

先排序再扫描连续段，容易理解但需要O(n log n)。如果要达到线性时间，就要在不排序的情况下快速查询相邻值，并避免从链中间反复扩展。

04 / 从直接做法推导改进

这里的“连续”指值相邻，例如 1、2、3，不要求它们在原数组中挨着。集合让 x+1 的存在性查询很快，但从每个元素都向后找，会反复扫描同一条链。

05 / 定义状态与更新规则

num_set去重并支持存在性查询；x必须没有前驱才开始扩展；y是当前链的终点，长度为y-x+1。

只从没有前驱 x-1 的数开始扩展。每条连续链只有一个起点，内部元素在外层检查时直接跳过，因此扩展循环总体只访问 O(n) 个不同值。外层要遍历去重后的集合。

from typing import List
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        ans = 0

        for x in num_set:
            # 只有 x-1 不存在时，x 才是一条连续链的起点。
            if x - 1 not in num_set:
                y = x
                while y + 1 in num_set:
                    y += 1
                ans = max(ans, y - x + 1)

        return ans

from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        # [0, slow) 是已处理好的非零区；fast 负责扫描。
        slow = 0

        for fast, x in enumerate(nums):
            if x != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1

from typing import List
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        ans = 0

        while left < right:
            area = min(height[left], height[right]) * (right - left)
            ans = max(ans, area)

            # 宽度一定变小，必须给较矮一侧换人。
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return ans

from typing import List
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n = len(nums)
        ans = []

        for i in range(n - 2):
            # 同一个“定一”值只允许作为起点出现一次。
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left, right = i + 1, n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    # 和太小：右移 left 让总和变大
                    left += 1
                elif total > 0:
                    # 和太大：左移 right 让总和变小
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])

                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    left += 1
                    right -= 1

        return ans

from typing import List
class Solution:
    def trap(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        left_max = right_max = 0
        ans = 0

        while left < right:
            if height[left] < height[right]:
                # 左侧更短时，右侧至少有不矮于右边界的屏障，
                # 当前点水量可由 left_max 单独决定。
                left_max = max(left_max, height[left])
                ans += left_max - height[left]
                left += 1
            else:
                right_max = max(right_max, height[right])
                ans += right_max - height[right]
                right -= 1

        return ans

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = 0
        last = {}  # char -> 最近一次出现下标
        ans = 0

        for right, ch in enumerate(s):
            # last[ch]>=left 才表示旧位置仍在窗口内；
            # 否则冲突早已被移出窗口。
            if ch in last and last[ch] >= left:
                left = last[ch] + 1

            last[ch] = right
            ans = max(ans, right - left + 1)

        return ans

05 / 定义状态与更新规则

cnt_p 是 p 的目标字符计数；cnt_s 是当前已加入且尚未移出的字符计数；ans 保存匹配窗口的起始下标。right 枚举右端点，left = right - len(p) + 1 是当前定长窗口应有的左端点。

每轮顺序固定为“入 → 判断是否满窗 → 比较 → 出”。先 cnt_s[c] += 1；若 left < 0，说明窗口还不够长，continue 保留已加入字符，不比较也不移出。

left >= 0 时，cnt_s 恰好统计 s[left:right+1]，长度为 len(p)。此时比较 cnt_s 与 cnt_p，匹配就记录 left；比较完成后再减去 s[left]，留下 len(p)-1 个字符，供下一轮加入新右端。

注意：比较时窗口长度为 len(p)，完整窗口这一轮结束时却只保留 len(p)-1 个字符。移出必须在比较之后，否则比较的不是完整窗口。

from collections import Counter
from typing import List


class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        cnt_p = Counter(p)
        cnt_s = Counter()
        ans = []

        for right, c in enumerate(s):  # 枚举右端点
            cnt_s[c] += 1  # 入：把右端字符加入窗口
            left = right - len(p) + 1  # 长度为 len(p) 的窗口起点
            if left < 0:  # 尚未凑够窗口长度，只积累，不比较、不移出
                continue
            if cnt_s == cnt_p:  # 当前窗口已经完整，比较字符次数
                ans.append(left)

            cnt_s[s[left]] -= 1  # 出：比较完成后移出左端，为下一轮腾出空间

        return ans

from collections import Counter


class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not t:  # 本地扩展边界：空目标无需覆盖
            return ""

        need = Counter(t)
        missing = len(t)
        left = start = 0
        best = float("inf")

        for right, ch in enumerate(s):
            # 只有真的缺这个字符时才减少总缺口；
            # 多余字符会把 need[ch] 减成负数。
            if need[ch] > 0:
                missing -= 1
            need[ch] -= 1

            # missing==0 表示所有有效字符都已覆盖
            while missing == 0:
                if right - left + 1 < best:
                    best = right - left + 1
                    start = left

                # 尝试移出左端字符
                need[s[left]] += 1

                # 加回后仍 <=0 说明它是多余的；
                # 加回后 >0 说明刚产生新缺口。
                if need[s[left]] > 0:
                    missing += 1
                left += 1

        return "" if best == float("inf") else s[start:start + best]

from collections import defaultdict
from typing import List


class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        count[0] = 1
        prefix = ans = 0

        for x in nums:
            prefix += x

            # 先查旧的差值，再加入当前前缀和；
            # 顺序反了会让当前段和自己配对。
            ans += count[prefix - k]
            count[prefix] += 1

        return ans

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

示例 1
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3 输出：[3,3,5,5,6,7]
示例 2
输入：nums = [1], k = 1 输出：[1]

02 / 先把题目读明白

每个长度为k的连续窗口都输出一个最大值；返回的是值列表，不是下标。

先确认：什么输入是合法的、最后返回或修改什么。暂时不需要猜算法名称。

03 / 最直接的做法

对每个窗口重新扫描最大值需要O(nk)。要减少扫描，保留仍可能成为未来最大值的候选，并淘汰更弱或过期的候选。

04 / 从直接做法推导改进

每个窗口重新扫描最大值要 O(nk)。只保留可能成为未来最大值的候选：若新来的数更大或相等，它比旧的小数更晚过期，旧小数便永远不再有用。

05 / 定义状态与更新规则

q保存下标，对应值递减；队头处理过期，队尾处理被新值淘汰；窗口形成后队头对应值就是最大值。

队列存下标，下标从头到尾递增，对应值严格递减（本代码弹出小于等于新值的队尾）。队头是当前最大值；保存下标才能判断是否已离开窗口。

06 / 手推一个完整例子

沿着下面的例子跟踪状态；每一步先自己预测，再看下一步。

  1. nums=[1,3,-1,-3,5,3,6,7]，k=3q 存下标
  2. right=0..11 被 3 淘汰；q=[1]，对应值 [3]
  3. right=2..3q 对应值 [3,-1,-3]；队头 3 输出
  4. right=4，值 5下标 1 过期；5 淘汰全部旧值；q=[4]
  5. right=6..76 淘汰 5，7 淘汰 6；输出 6,7

07 / 把思路写成完整代码

nums=[1,3,-1,-3,5]、k=3：下标0入队[0]；3淘汰1，队列[1]；-1入队[1,2]，输出3；-3入队[1,2,3]，输出3；到5先删除过期下标1，再从队尾删除3、2，入队[4]，输出5。队头过期用popleft，队尾被更强值淘汰用pop。

from collections import deque
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        q = deque()  # 存下标；对应值保持单调递减
        ans = []

        for right, x in enumerate(nums):
            # 队头已经滑出 [right-k+1,right]，先弹出
            if q and q[0] <= right - k:
                q.popleft()

            # 新值更强/等强时，旧队尾永远不可能成为后续答案
            while q and nums[q[-1]] <= x:
                q.pop()

            q.append(right)

            if right >= k - 1:
                ans.append(nums[q[0]])

        return ans
